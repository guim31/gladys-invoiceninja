# Changelog

All notable changes to this integration are documented in this file. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
uses [semantic versioning](https://semver.org/).

Describe each change under `## [Unreleased]` as you make it. The Release
workflow moves that section under the version it ships, and the section becomes
the notes of the version's GitHub Release.

## [Unreleased]

### Added

- Invoice Ninja 5 in Gladys, self-hosted or on invoicing.co, with an API token: a device for the
  company with its unpaid invoices (count and amount), overdue invoices (count and amount), money
  received this month and pending quotes.
- Scene triggers: payment received, invoice overdue, quote accepted.
- Scene action: read the summary, as a sentence to send or read aloud, with its numbers.
- Dashboard widget: totals, overdue invoices and latest payments, each block and the amounts
  hideable.
- Texts and documentation in English, French, German and Spanish.
